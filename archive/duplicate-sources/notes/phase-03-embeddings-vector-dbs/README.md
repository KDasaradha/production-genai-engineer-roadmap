# Phase 3: Embeddings and Vector Databases

This phase turns LLM theory into retrieval systems. You will learn how semantic search works, how to chunk documents, and how vector databases support RAG.

## Topics

1. [Embedding Types](01-embedding-types.md)
2. [Retrieval Strategies](02-retrieval-strategies.md)
3. [Chunking Strategies](03-chunking-strategies.md)
4. [Vector Databases](04-vector-databases.md)

## Outcome

You should be able to build a semantic search engine and explain dense, sparse, hybrid retrieval, chunking, and vector database tradeoffs.
