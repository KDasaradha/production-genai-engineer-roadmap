# GenAI Learning Notes

This is your structured learning system for moving from Python backend developer to production-ready GenAI engineer.

Use this folder as the main study path. Keep `Agents.md` as the teaching style guide and `Roadmap.md` as the original roadmap source.

## Weekly Routine

| Day | Activity | Target |
| --- | --- | --- |
| Monday | Concept learning + notes | Understand one topic deeply |
| Tuesday | Python implementation | Convert concept into code |
| Wednesday | FastAPI or system design | Connect concept to backend work |
| Thursday | Production concerns | Logging, failure modes, cost, security |
| Friday | Interview preparation | Practice model answers |
| Saturday | Project building | Build portfolio features |
| Sunday | Revision + quiz | Find gaps and repeat weak topics |

## Daily Routine

| Time Block | Activity |
| --- | --- |
| Hour 1 | Read one section slowly and summarize it |
| Hour 2 | Implement the Python example by hand |
| Hour 3 | Add a production or FastAPI version |
| Optional Hour 4 | Answer interview questions and update notes |

## Learning Rules

- Study one section at a time.
- Do not skip the quiz.
- Do not move forward until you can explain the topic simply.
- For every topic, learn the definition, use cases, tradeoffs, limitations, production example, and interview answer.
- Prefer building small working examples over only reading theory.

## Interview Path

Use [Interview Prep](interview-prep.md) after each phase. Do not wait until the end.

For every topic, prepare:

- A 30-second beginner explanation.
- A 2-minute production explanation.
- One system design example.
- One failure mode and how to fix it.
