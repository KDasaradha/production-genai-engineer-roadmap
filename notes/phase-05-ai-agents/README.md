# Phase 5: AI Agents Engineering

AI agents combine LLMs with tools, state, memory, planning, and workflows. This phase teaches how to build agents without losing control of cost, safety, and reliability.

## Topics

1. [Agent Fundamentals](01-agent-fundamentals.md)
2. [Tool Calling](02-tool-calling.md)
3. [State, Memory, and Orchestration](03-state-memory-orchestration.md)
4. [Agent Frameworks](04-agent-frameworks.md)

## Outcome

You should be able to design a bounded tool-using workflow and explain when agents are useful, risky, or unnecessary.
