# Phase 1: LLM Foundations

This phase teaches the foundations behind modern large language model systems. Do not rush this phase. Prompt engineering, RAG, agents, and fine-tuning all depend on these concepts.

## Topics

1. [Tokens and Tokenization](01-tokens-and-tokenization.md)
2. [Embeddings](02-embeddings.md)
3. [Cosine Similarity](03-cosine-similarity.md)
4. [Context Windows](04-context-windows.md)
5. [Temperature and Top-P](05-temperature-top-p.md)
6. [Hallucinations](06-hallucinations.md)
7. [Transformer Basics](07-transformer-basics.md)

## Outcome

After this phase, you should be able to explain how text becomes model input, how semantic similarity works, why output randomness changes, why hallucinations happen, and why transformer architecture changed NLP.
