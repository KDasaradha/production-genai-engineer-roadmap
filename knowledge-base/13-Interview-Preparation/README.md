## Answer Format

Use this structure for most interview answers:

```text
Definition -> Why it matters -> How it works -> Tradeoffs -> Production example
```

For system design:

```text
Requirements -> APIs -> Data model -> Architecture -> Bottlenecks -> Tradeoffs -> Monitoring
```

## Common Trap

Do not give only definitions. Interviewers usually want tradeoffs, failure modes, and production examples.
