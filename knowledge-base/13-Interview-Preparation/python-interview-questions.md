# Python Interview Questions

## Questions

1. What is the difference between synchronous and asynchronous programming?
Answer: Synchronous code blocks sequentially, while asynchronous code yields control during waits so other tasks can progress.

2. What is a generator and why is it useful?
Answer: A generator yields values lazily and preserves state, which makes it useful for memory-efficient iteration and streaming.

3. Why use decorators?
Answer: Decorators attach repeated cross-cutting behavior such as logging, auth, caching, or retries without rewriting the same logic in many functions.

4. What problem do context managers solve?
Answer: They guarantee setup and cleanup around resource usage such as files, DB sessions, or locks.

5. What are type hints and why use `mypy`?
Answer: Type hints make intent explicit and improve static checking, editor support, and refactor safety; `mypy` validates them before runtime.
