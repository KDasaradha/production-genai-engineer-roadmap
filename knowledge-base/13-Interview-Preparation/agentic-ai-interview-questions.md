# Agentic AI Interview Questions

## Questions

1. What is an AI agent?
Answer: An agent is a system that uses an LLM with tools, state, and control logic to perform multi-step work toward a goal.

2. When should you use an agent?
Answer: Use an agent when the task requires tool use, branching decisions, planning, or memory across steps.

3. Why are agents riskier than normal prompt-response systems?
Answer: They add latency, cost, failure modes, loop risk, and tool misuse possibilities.

4. How do you stop infinite loops?
Answer: Add step limits, tool budgets, state checks, evaluator nodes, and explicit termination rules.

5. Memory vs context?
Answer: Context is what the model sees in the current prompt; memory is the stored state or summaries that can be selectively brought back into future steps.
