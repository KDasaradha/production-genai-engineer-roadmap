# GenAI Interview Questions

## Questions

1. What is a token?
Answer: A token is a chunk of text a model consumes and generates, and it affects cost, latency, and context limits.

2. What is an embedding?
Answer: An embedding is a vector representation of data that places semantically similar items near each other in vector space.

3. What is cosine similarity?
Answer: It measures the angle-based similarity between vectors and is commonly used to rank semantic closeness.

4. Why do hallucinations happen?
Answer: LLMs generate plausible next tokens rather than guaranteed facts, so weak grounding or ambiguous context can produce confident errors.

5. Temperature vs top-p?
Answer: Temperature scales randomness across the distribution, while top-p narrows generation to the smallest token set covering a chosen cumulative probability.
