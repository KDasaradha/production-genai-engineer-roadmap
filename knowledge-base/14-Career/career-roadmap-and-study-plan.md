# Career Roadmap and Study Plan

## Target Roles

| Role | Fit | Why |
| --- | --- | --- |
| AI Backend Engineer | High | Strong match for Python, FastAPI, APIs, storage, and service design |
| RAG Engineer | High | Direct fit for retrieval, vector DBs, grounding, and knowledge systems |
| Agentic AI Engineer | High | Good fit once orchestration, tools, and state management are strong |
| GenAI Engineer | High | Requires balanced skills across prompting, systems, and production deployment |
| AI Product Engineer | Medium | Stronger fit if frontend/product UX work becomes part of the portfolio |

## Recommended Strategy

Use this weighting:

- 20% theory
- 30% architecture and tradeoffs
- 50% implementation and projects

## Portfolio Progression

1. AI Text Summarizer
2. Semantic Search Engine
3. AI Streaming Chat API
4. Knowledge Assistant
5. Enterprise RAG Platform
6. Multi-Agent Research System
7. Production AI Platform

## Weekly Study Plan

| Day | Focus | Output |
| --- | --- | --- |
| Monday | Learn one concept | Summary note in your own words |
| Tuesday | Build Python example | Working local code |
| Wednesday | Add FastAPI or storage integration | Small service or route |
| Thursday | Study failures and production concerns | Debug notes or tradeoff notes |
| Friday | Practice interview answers | Short and deep answers |
| Saturday | Build portfolio feature | Commit or demo artifact |
| Sunday | Review and plan next week | Updated tracker and study plan |

## Hiring-Focused Advice

- Favor production-flavored backend AI projects over toy chatbots.
- Be able to explain why you chose a retrieval strategy, cache policy, or agent boundary.
- Keep one flagship RAG project and one flagship agentic workflow project interview-ready.
- Prepare architecture explanations, not only code walkthroughs.

## What To Avoid

- Collecting many half-finished demos
- Learning only framework APIs without understanding core concepts
- Calling every workflow an agent
- Treating prompt engineering as a substitute for architecture and evaluation
