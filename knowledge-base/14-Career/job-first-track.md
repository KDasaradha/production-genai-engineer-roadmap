# Job-First Track

## Goal

This track prioritizes the fastest path to interview readiness and a credible portfolio, rather than complete coverage of every GenAI topic first.

## Shortest Path

1. Backend foundation: AsyncIO, FastAPI, PostgreSQL, Redis
2. LLM basics: tokens, embeddings, context windows, hallucinations
3. Prompting: prompt types, structured outputs, prompt security
4. RAG core: chunking, retrieval, vector DBs, RAG pipeline
5. One flagship project: Enterprise RAG Platform
6. One agent project: Research Agent or Coding Assistant
7. Production topics: observability, CI/CD, cloud architecture

## 18-Week Shape

| Stage | Weeks | Focus |
| --- | --- | --- |
| Stage 1 | 1-8 | Backend + LLM + prompt basics |
| Stage 2 | 9-14 | Retrieval + RAG + flagship project |
| Stage 3 | 15-18 | Agent workflow + interview prep + production polish |

## What To Skip Early

- Deep fine-tuning internals
- Exotic agent frameworks
- Overly broad cloud specialization
- Too many toy projects

## What To Show in Interviews

- One strong backend AI service
- One strong RAG system
- One discussion-ready agent workflow
- Clear tradeoff reasoning on latency, cost, and reliability
