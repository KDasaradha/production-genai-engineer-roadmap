## Role Targets

| Role | Strongest Evidence |
| --- | --- |
| Python Backend Developer | FastAPI API, PostgreSQL, Redis, Docker, tests |
| AI Backend Engineer | Streaming chat API, prompt evaluation, observability |
| RAG Engineer | Semantic search, knowledge assistant, enterprise RAG |
| Agent Engineer | Tool calling, workflow automation, multi-agent research |
| Production GenAI Engineer | Production AI platform with monitoring, security, scaling, and cost controls |

## Job-Ready Checklist

- Can explain core topics clearly in 2 minutes.
- Can build a FastAPI service without copying.
- Can use PostgreSQL and Redis in realistic workflows.
- Can explain tokens, embeddings, context windows, hallucinations, and RAG.
- Can build at least one RAG project with citations.
- Can discuss security, monitoring, cost, latency, and scaling.
- Has at least two polished portfolio projects.

## Common Trap

Do not wait until you feel advanced in every topic before applying. Build evidence, practice explanations, and apply while improving.
