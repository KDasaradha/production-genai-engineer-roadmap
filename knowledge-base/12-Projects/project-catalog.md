# Project Catalog

## Purpose

This file consolidates named projects scattered across the roadmap chats into a single project source of truth.

## Beginner Projects

| Project | Goal | Core Skills |
| --- | --- | --- |
| AI Text Summarizer | Summarize long text with prompts and structured outputs | Prompting, chunking, output formatting |
| Semantic Search Engine | Retrieve semantically similar documents or notes | Embeddings, cosine similarity, APIs |
| Multi-Provider AI Playground | Compare model behavior across providers | Prompting, provider abstraction, evaluation |
| AI Summarizer | Convert articles or PDFs into concise summaries | LLM basics, prompt design, FastAPI |

## Intermediate Projects

| Project | Goal | Core Skills |
| --- | --- | --- |
| AI Streaming Chat API | Stream model responses via FastAPI | AsyncIO, FastAPI, streaming, Redis |
| Knowledge Assistant | Answer questions from indexed documents | Vector DBs, retrieval, citations |
| Resume Analyzer | Score resumes and return feedback | Structured outputs, prompt testing, validation |
| Contract Analyzer | Extract clauses and risks from documents | Structured outputs, document parsing, guardrails |
| Prompt Evaluation System | Compare prompts against a benchmark | Prompt versioning, metrics, regression testing |

## Advanced Projects

| Project | Goal | Core Skills |
| --- | --- | --- |
| Enterprise RAG Platform | Production document Q&A with citations | Ingestion, retrieval, reranking, monitoring |
| Research Agent | Plan, search, and synthesize findings | Tool calling, orchestration, memory |
| Coding Assistant | Code explanation, retrieval, and agent workflows | Code search, RAG, tools, safety |
| AI Workflow Automation | Use AI inside business workflows | Tool integration, queues, retries |
| SaaS-Level AI Product | User-facing AI app with auth and product UX | Full-stack app patterns, sessions, observability |

## Production Projects

| Project | Goal | Core Skills |
| --- | --- | --- |
| Production AI Platform | Unified AI delivery platform | CI/CD, observability, scaling, cost control |
| Offline Local AI System | Run retrieval or assistant workflows locally | Local models, vector DBs, optimization |
| Fine-Tuned Domain Assistant | Customize model behavior for a domain | Fine-tuning, evaluation, deployment |
| AI Security Gateway | Protect AI endpoints and prompts | Guardrails, rate limits, abuse prevention |
| UK Council Planning Portal AI Platform | Council-specific planning assistant with rules and citations | Multi-tenant RAG, rule engine, metadata filtering, audit logs |

## Recommended Build Order

1. AI Text Summarizer
2. Semantic Search Engine
3. AI Streaming Chat API
4. Knowledge Assistant
5. Resume Analyzer
6. Enterprise RAG Platform
7. Research Agent or Coding Assistant
8. Production AI Platform
9. UK Council Planning Portal AI Platform
