# Note Templates and Prompts

## Purpose

This file preserves the reusable teaching and note-organization structures from the raw prompt files.

## Core Teaching Pattern

Use this structure when expanding or rewriting a topic:

1. Problem Statement
2. Beginner Explanation
3. Intermediate Explanation
4. Advanced Explanation
5. Internal Working
6. When To Use
7. When Not To Use
8. Advantages
9. Tradeoffs
10. Limitations
11. Real-World Examples
12. Architecture Diagram
13. Python Implementation
14. FastAPI Implementation
15. Database Integration
16. Production Considerations
17. Common Mistakes
18. Interview Preparation
19. System Design Discussion
20. Hands-On Assignment
21. Mini Project
22. Production-Level Project
23. Quiz
24. Knowledge Check

## Alternate Lightweight Pattern

When a full deep-dive is unnecessary, use:

- Overview
- Beginner Level
- Intermediate Level
- Advanced Level
- FastAPI Perspective
- Generative AI Perspective
- Agentic AI Perspective
- Interview Preparation
- Production Examples
- Best Practices
- Comparison Section
- Hands-on Exercises
- Mini Project
- Summary
- Cheat Sheet
