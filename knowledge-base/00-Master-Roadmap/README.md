# Master Roadmap

This folder is the control center for the knowledge base. Use it before jumping into individual topic notes.

## Recommended Order

| Order | File | Use It For |
| --- | --- | --- |
| 1 | [Start-Here.md](Start-Here.md) | Understand the goal, path, and minimum job-ready standard |
| 2 | [Learning-Roadmap.md](Learning-Roadmap.md) | Follow the dependency-aware curriculum |

## Best Use

1. Read [Start-Here.md](Start-Here.md).
2. Pick a stage from [Learning-Roadmap.md](Learning-Roadmap.md).
3. Study the matching topic folder.
4. Build the suggested project from [12-Projects](../12-Projects/README.md).
5. Practice interview questions from [13-Interview-Preparation](../13-Interview-Preparation/README.md).
6. Update [Progress-Tracker.md](Progress-Tracker.md) every week.

## Readiness Rule

A topic is not complete until you can explain it simply, implement a working example, debug common failures, name tradeoffs, and answer interview follow-ups.
