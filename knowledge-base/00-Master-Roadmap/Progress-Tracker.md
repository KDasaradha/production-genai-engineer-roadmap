# Progress Tracker

Update this weekly. Mark a topic as complete only when you can explain it, implement it, debug it, and answer interview follow-ups.

## Readiness Scale

| Status | Meaning |
| --- | --- |
| `Not Started` | You have not studied it yet |
| `Learning` | You understand the idea but cannot explain or implement it cleanly |
| `Practicing` | You can build examples but still make mistakes under pressure |
| `Interview Ready` | You can explain tradeoffs and answer follow-up questions |
| `Production Ready` | You can design, build, debug, monitor, and defend it in a real system |

## Weekly Review Prompts

1. Which topic can I explain simply without notes?
2. Which topic can I implement from scratch?
3. Which topic can I defend in an interview?
4. Which topic still breaks under real-world edge cases?
5. Which project artifact can I show publicly?
