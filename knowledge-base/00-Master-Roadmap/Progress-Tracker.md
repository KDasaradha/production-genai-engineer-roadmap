# Progress Tracker

## How To Use

Update this file weekly. Mark a topic as done only when you can explain it, implement it, debug it, and answer interview questions on it.

## Readiness Scale

| Status | Meaning |
| --- | --- |
| `Not Started` | You have not studied it yet |
| `Learning` | You understand the idea but cannot explain or implement it cleanly |
| `Practicing` | You can build examples but still make mistakes under pressure |
| `Interview Ready` | You can explain tradeoffs and answer follow-up questions |
| `Production Ready` | You can design, build, debug, and monitor it in a real system |
