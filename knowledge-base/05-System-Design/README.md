## What To Master

| Area | Why It Matters |
| --- | --- |
| Requirements | Good design starts with scope, users, latency, cost, and data needs |
| APIs | Interfaces define how clients and services interact |
| Data model | Storage decisions shape correctness and performance |
| Scaling | Bottlenecks appear in API, DB, cache, vector search, and model calls |
| Reliability | Production systems need retries, queues, fallbacks, and monitoring |
| Tradeoffs | Interviewers care more about reasoning than memorized diagrams |

## Common Trap

Do not start with technology choices. Start with requirements, constraints, traffic, data flow, and failure modes.
